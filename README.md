# SanD Hacks 2026

This repository was created for SanD Hacks 2026. The substantive implementation and documentation for our **DysphaGrip** prototype are maintained in a separate repository:

**[DysphaGrip — source code and project documentation](https://github.com/maxhrdz/test2)**

DysphaGrip combines audio from a contact microphone with motion readings from an MPU6050 connected to Arduino. The Python application visualizes both streams and records experimental candidate events.

It is a research prototype, **not** a medical device or a validated detector of swallowing safety or aspiration.

This repository serves as a hackathon reference and does not contain the main application code.
